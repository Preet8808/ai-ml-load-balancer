# requirements.txt is what the service images install, and it holds only what
# the running services import. The ML stack below is needed to train a model,
# to run the signal gate, and by pytest - all of which happen on the host, so
# CI and local development install this file instead.
#
#   pip install -r requirements-dev.txt
#
# This split also matters for build time: every wheel in the image is
# re-downloaded on each rebuild, because the image build installs with
# --no-cache-dir. Adding the ML stack to the image turned a 40-second rebuild
# into one that had not finished after 15 minutes.
